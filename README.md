# Fitness Tracker

Mobile-first personal fitness, mobility, running, and nutrition tracker.

## MVP goals
- Today view with today's workout and quick check-ins
- Strength logging with last-session context
- Push-up and pull-up progression
- Running + knee response tracking
- Mobility + split tracking
- Nutrition targets and quick adherence tracking
- Planned travel/deload blocks

## Tech
- Next.js
- TypeScript
- Tailwind CSS
- Client-side local storage for the first prototype

A database/auth layer can be added later once the interaction model feels right.
